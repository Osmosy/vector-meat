# Vector Meat — штатное расписание (первая редакция)

Виртуальные сотрудники Vector Work на мясоперерабатывающем заводе. 13 штатных единиц.

## Оргструктура

```
ДИРЕКТОР ЗАВОДА
├── ПРОИЗВОДСТВО
│   ├── Главный технолог (product-management)
│   ├── Главный инженер (engineering)
│   ├── Микробиолог ОТК (bio-research)
│   └── Технолог-упаковщик (design)
├── КАЧЕСТВО И УЧЁТ
│   ├── Специалист Меркурий / Честный Знак (enterprise-search)
│   ├── Бухгалтер (finance)
│   └── Аналитик производства (data)
├── СНАБЖЕНИЕ И СБЫТ
│   ├── Начальник снабжения (operations)
│   └── Специалист по закупкам (small-business)
├── КАДРЫ И АДМИНИСТРАЦИЯ
│   ├── Кадровик (human-resources)
│   ├── Делопроизводитель (productivity)
│   └── Юрисконсульт (legal)
└── РАЗВИТИЕ
    └── Куратор ИИ-трансформации (cowork-plugin-management)
```

## Приоритет активации

| Очерёдность | Работник | Причина |
|------------|---------|--------|
| **P0 — запустить первым** | Специалист Меркурий / ЧЗ | Ошибки в госсистемах = остановка отгрузок |
| **P0 — запустить первым** | Микробиолог ОТК | Без ХАССП завод не работает |
| **P1 — неделя 1** | Главный технолог | Рецептуры и нормы — ядро производства |
| **P1 — неделя 1** | Бухгалтер | Себестоимость и отчётность |
| **P2 — неделя 2** | Главный инженер | Оборудование уже работает, ТО по графику |
| **P2 — неделя 2** | Начальник снабжения | Вендоры и поставки |
| **P3 — неделя 3** | Аналитик производства | Дашборды — когда есть данные |
| **P3 — неделя 3** | Кадровик | Найм — когда определились с потребностью |
| **P4 — неделя 4** | Остальные (юрист, делопроизводитель, закупщик, упаковщик) |
| **P5 — месяц 2** | Куратор ИИ | Когда первые работники показали результат |

## Взаимодействие с людьми

Каждый виртуальный работник закреплён за живым сотрудником:

| Виртуальный работник | Живой сотрудник |
|---------------------|----------------|
| Главный технолог | Главный технолог (человек проверяет рецептуры) |
| Микробиолог ОТК | Начальник лаборатории (человек делает посевы) |
| Специалист Меркурий / ЧЗ | Оператор Меркурия (человек подписывает ЭЦП) |
| Бухгалтер | Главбух (человек заверяет отчётность) |
| ... | ... |

**Правило:** виртуальный работник готовит → живой сотрудник проверяет и утверждает. ИИ не имеет права подписи в госсистемах и финансовых документах.
