## Оргструктура завода

```
ДИРЕКТОР ЗАВОДА
├── ПРОИЗВОДСТВО
│   ├── Главный технолог — рецептуры, нормы выхода, ассортимент
│   ├── Главный инженер — оборудование, ТО, промбезопасность
│   ├── Микробиолог ОТК — ХАССП, сроки годности, протоколы
│   └── Технолог-упаковщик — этикетки, compliance с ГОСТ
├── КАЧЕСТВО И УЧЁТ
│   ├── Спец Меркурий / ЧЗ — эВСД, маркировка, сверка партий
│   ├── Бухгалтер — проводки, себестоимость, отчётность
│   └── Аналитик производства — дашборды, план/факт, аномалии
├── СНАБЖЕНИЕ И СБЫТ
│   ├── Начальник снабжения — вендоры, цепочка поставок
│   └── Специалист по закупкам — инвойсы, учёт ТМЦ
├── КАДРЫ И АДМИНИСТРАЦИЯ
│   ├── Кадровик — найм, медкнижки, обучение
│   ├── Делопроизводитель — задачи, протоколы
│   └── Юрисконсульт — договоры, претензии
└── РАЗВИТИЕ
    └── Куратор ИИ — создание новых ролей, аудит
```

## Процессы завода

Сырьё (полутуши/отрубы) → приёмка по качеству и весу → обвалка → жиловка → посол/маринование → формовка → термообработка → охлаждение → фасовка → упаковка → маркировка → отгрузка.

Вспомогательные: мойка/санитария, холодильное оборудование, ТО, лаборатория.

## Регуляторика

- **ФГИС Меркурий** — электронные ветеринарные свидетельства (эВСД)
- **Честный Знак** — маркировка продукции
- **ХАССП** — система безопасности пищевой продукции

## Быстрый старт

```bash
git clone https://github.com/Osmosy/vector-meat.git

# Посмотреть план внедрения
hermes --skills vector-meat-ai-plan "на какой мы стадии?"

# Посмотреть штатное расписание
cat docs/staffing-v1.md

# Запустить виртуального сотрудника
hermes --skills vector-work "проверь партию говядины в Меркурии по накладной №456"
```

## Принципы

1. **Виртуальный работник готовит → человек утверждает.** ИИ не подписывает госсистемы.
2. **Данные локально.** Ни одна рецептура не уходит в облако.
3. **Метрика у каждого процесса.** Без baseline ИИ не внедряется.
4. **Сначала Меркурий и микробиолог.** Ошибки здесь = остановка завода.
