Центральный хаб завода. Объединяет всё связанное с работниками, процессами и ИИ на мясопереработке.

## Оргструктура

```
ДИРЕКТОР ЗАВОДА
├── ПРОИЗВОДСТВО
│   ├── Главный технолог — рецептуры, нормы выхода
│   ├── Главный инженер — оборудование, ТО
│   ├── Микробиолог ОТК — ХАССП, сроки годности
│   └── Технолог-упаковщик — этикетки, ГОСТ
├── КАЧЕСТВО И УЧЁТ
│   ├── Спец Меркурий / ЧЗ — эВСД, маркировка
│   ├── Бухгалтер — себестоимость, отчётность
│   └── Аналитик производства — дашборды, план/факт
├── СНАБЖЕНИЕ И СБЫТ
│   ├── Начальник снабжения — вендоры, поставки
│   └── Специалист по закупкам — инвойсы, ТМЦ
├── КАДРЫ И АДМИНИСТРАЦИЯ
│   ├── Кадровик — найм, медкнижки
│   ├── Делопроизводитель — задачи, протоколы
│   └── Юрисконсульт — договоры, претензии
└── РАЗВИТИЕ
    └── Куратор ИИ — новые роли, аудит
```

## Процессы

Сырьё (полутуши/отрубы) → приёмка → обвалка → жиловка → посол → формовка → термообработка → охлаждение → фасовка → упаковка → маркировка → отгрузка.

## Регуляторика

- **ФГИС Меркурий** — электронные ветеринарные свидетельства
- **Честный Знак** — маркировка продукции
- **ХАССП** — безопасность пищевой продукции

## Принципы

1. **Виртуальный работник готовит → человек утверждает.** ИИ не подписывает госсистемы.
2. **Данные локально.** Ни одна рецептура не уходит в облако.
3. **Метрика у каждого процесса.** Без baseline ИИ не внедряется.
4. **Сначала Меркурий и микробиолог.** Ошибки здесь = остановка завода.
